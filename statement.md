# Game Progress Tracker



## Problem Statement



Tracking progress of multiple games can be devastating , difficult and rigrous when hours played, percentage completed, status, rating , game type and mode and other details are not properly organized.



The Game Progress Tracker is a Python(basic program) based application that allows the individual to store and manage their game information regarding their game info and various other things. This application allows the user to add games, view and search games, update their progress, calculate statistics and generate reports(Game report and overall report).



This project applies problem solving and programming concepts such as algorithms, variables, data types, conditional statements, loops, functions, lists and dictionaries.



## Scope


This project's scope is to manage game progress using an in-memory Python list containing dictionaries



The application includes the following features:



1. Add game

2. View games

3. Search game



4. Update game progress

5. Calculate game statistics

6. Generate reports (individual game and overall)

The project does not make use of a database or anyother external network or library which is not mentioned in the sllyabus.

## Target Users

The application is targeted towards the following:

i. Students learning Python programming

ii.  Gamers who wish to track their progress

iii. Users who wish to have command line based simple game tracking application
